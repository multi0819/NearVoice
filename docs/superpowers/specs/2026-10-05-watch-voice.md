# Watch Ultra voice
User wants screen-off phone reminders spoken on Galaxy Watch Ultra, preserving phone silence in watch mode. Phone and Wear OS APKs share application ID and test certificate for authenticated Data Layer delivery. Existing phone behavior stays intact outside watch mode.
Phone sends one current event to one reachable watch advertising nearvoice_voice_v1, with bounded capability/send/acceptance-ACK timeouts and visible notification fallback. Watch user starts a persistent foreground voice receiver from its Activity; it stays idle without a wake lock and holds a timed wake lock only while speaking. WearableListenerService validates fresh, bounded payloads and deduplicates event IDs. If automatic foreground startup is blocked, show a tap-to-read notification and preserve the last message. No promise of disconnected autonomous scheduling. Watch shows last message and local Korean TTS test, supports receiver stop and volume guidance.
Verification: phone event policy regressions, watch event-age and length rules, Gradle unit tests/lint/build on CI, APK package/signing verification. Real-watch installation, screen-off delivery and Korean engine availability remain device tests.
