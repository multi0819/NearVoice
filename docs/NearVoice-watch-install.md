# NearVoice 1.0.4 · 워치 울트라 설치

휴대폰과 워치에 서로 다른 APK를 설치해야 합니다. 워치 APK를 휴대폰에서 직접 열면 워치에 설치되지 않습니다.

## 1. 휴대폰 업데이트
NearVoice-phone.apk를 내려받아 기존 앱 위에 설치합니다. 기존 앱은 삭제하지 마세요. 저장된 예약이 유지됩니다.

## 2. 휴대폰에서 워치 APK 설치
1. 휴대폰과 워치를 같은 Wi-Fi에 연결합니다.
2. 휴대폰에 Wear Installer(개발자 Malcolm Bryant)를 설치합니다. 공식 안내와 설치 링크: https://freepoc.org/wear-installer-help-page/
3. 워치 설정 → 워치 정보 → 소프트웨어 정보 → 소프트웨어 버전을 여러 번 눌러 개발자 옵션을 켭니다.
4. 워치 개발자 옵션에서 ADB 디버깅과 무선 디버깅을 켭니다. 무선 디버깅 화면의 IP 주소를 휴대폰 Wear Installer에 입력합니다.
5. Wear Installer 메뉴에서 Pair with watch → Enable을 선택합니다. 워치의 무선 디버깅에서 새 기기 페어링을 눌러 표시되는 코드와 페어링 포트를 Wear Installer에 입력합니다. 코드는 다른 사람에게 보낼 필요가 없습니다.
6. 페어링 후에는 무선 디버깅 기본 화면에 표시되는 연결 포트를 Wear Installer에 입력합니다. 페어링 포트와 연결 포트는 다릅니다.
7. Wear Installer의 Custom APK에서 내려받은 NearVoice-watch.apk를 선택하고 Install을 누릅니다.
8. 설치 후 워치의 무선 디버깅과 ADB 디버깅을 끕니다.

## 3. 음성 수신 켜기
1. 워치에서 NearVoice 워치를 엽니다.
2. 알림 권한을 허용하고 한국어 음성 테스트를 누릅니다.
3. 소리가 안 나면 워치 알람 음량과 한국어 음성 합성 데이터/엔진을 확인합니다. 앱은 알람 오디오를 사용합니다. 블루투스 이어폰 연결 상태에 따라 출력 경로가 바뀔 수 있습니다.
4. 워치에서 음성 수신 ON을 누릅니다. 수신 ON을 켠 상태에서 화면을 꺼도 메시지를 기다립니다.
5. 휴대폰 NearVoice 설정에서 워치 모드를 켭니다.
6. 휴대폰에서 메시지 음성 읽기를 켠 시간 예약을 2~3분 뒤로 저장하고 전체 ON 상태에서 휴대폰·워치 화면을 끕니다.

## 동작과 제한
- 휴대폰 화면이 켜져 있으면 기존 휴대폰 재생입니다.
- 화면 OFF + 워치 모드에서는 워치에 메시지를 보내며, 수신 ON인 워치 앱이 읽습니다.
- 워치 음성 재생은 예약의 음성/진동 선택을 따릅니다. 선택한 휴대폰 알림음은 워치로 복사하지 않습니다.
- 워치 앱이 없거나 연결·수신 응답이 없으면 문자 알림으로 전달합니다. 휴대폰에서 음성을 대신 읽지는 않습니다.
- 기존 Galaxy Wearable 문자 알림을 워치 앱 알림과 함께 켜면 문자 표시가 중복될 수 있습니다.
- 워치 재부팅·강제 종료 후에는 음성 수신 ON을 다시 눌러야 합니다.
- 화면 OFF 음성 재생, 기기별 절전 상태, 한국어 TTS는 실제 워치에서 확인해야 합니다. 빌드와 단위 검증만 통과한 테스트용 APK입니다.

## PC로 설치하는 경우
최신 Android SDK Platform Tools를 설치하고 같은 Wi-Fi에서 아래 명령을 실행합니다.

    adb pair 워치IP:페어링포트
    adb connect 워치IP:연결포트
    adb -s 워치IP:연결포트 install -r NearVoice-watch.apk

첫 명령을 실행하면 워치에 표시된 페어링 코드를 입력합니다. 자세한 공식 문서: https://developer.android.com/training/wearables/get-started/debug-wifi

## 워치 v1.0.5 업데이트

휴대폰 v1.0.4는 그대로 사용하고 워치만 v1.0.5 APK로 덮어 설치합니다. 예약 알림을 높은 중요도의 새 채널로 표시합니다. 기존 채널의 중요도는 앱이 변경할 수 없으므로 채널을 새로 만들며, 기존 채널은 삭제하지 않습니다. 음성과 진동은 기존 예약 설정을 따릅니다. Galaxy Wearable의 알림 수신 시 화면 켜기와 상세 내용 표시를 켜고 화면 OFF 상태에서 테스트하세요. 높은 중요도는 알림 표시 요청이며 화면 켜짐을 강제로 보장하지 않습니다.
