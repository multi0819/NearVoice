# 구글 지도에서 목적지 찾기

휴대폰 v1.0.10, 워치 v1.0.6을 사용합니다. API 키나 별도 결제 계정 등록은 필요하지 않습니다.

예약의 지도 버튼 → 구글 지도에서 찾기 → 장소명 검색 → 장소 정보의 공유 → NearVoice → 위치 확인 → 이 위치 선택 → 예약 저장. 구글 지도에서 먼저 공유해도 새 위치 예약을 만들 수 있습니다. 집/회사 등록 중 공유하면 해당 등록 화면에 적용됩니다. 공유는 목적지만 채우며 예약을 자동 저장하지 않습니다.

구글 지도 공유 링크 형식에 따라 장소 좌표가 포함되지 않을 수 있습니다. 이때는 주소 검색 또는 지도에서 지점을 직접 확인해야 합니다. 지도 화면 중앙 좌표를 목적지로 잘못 사용하지 않습니다. 짧은 공유 링크는 구글 지도 서버의 리디렉션을 확인하므로 인터넷 연결이 필요합니다. 지도에서 돌아오기 전 앱 프로세스가 종료되면 작성 중인 미저장 입력은 복원되지 않습니다.

## v1.0.10

다른 장소 선택 → 구글 지도에서 장소명 검색 → 공유 → NearVoice → 이 위치 선택 순서로 사용합니다. 공유 링크에 좌표가 없으면 구글 지도 공개 장소 페이지에서 같은 장소 ID의 좌표를 확인합니다. API 키 등록은 필요하지 않습니다. 솔브레인 본사 링크의 건물 좌표는 37.4060459, 127.0896802로 확인했습니다.

구글 지도 공유 주소를 휴대폰 주소 검색으로 다시 검색하지 않습니다. 건물 좌표를 확인하지 못하면 선택을 요청하며 도로 중심을 자동 등록하지 않습니다. 공개 페이지 형식 변경이나 네트워크 상태에 따라 가져오기가 실패할 수 있습니다. 자체 지도에 건물명이나 주소가 없어도 확인된 좌표에 표시됩니다. 워치 앱은 v1.0.6을 유지합니다.
