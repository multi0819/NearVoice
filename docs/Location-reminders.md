# 위치 알림 v1.0.12

위치 모드는 설정 시각을 확인하지 않지만 선택 날짜 또는 요일 조건은 적용합니다. 날짜 선택 예약은 선택한 날에 한 번 실행합니다.

저장 또는 감지 시작 시 2분 이내, 정확도 100m 이내의 최근 위치가 있으면 즉시 재검사합니다. 현재 목적지 반경 안이면 이동하지 않아도 실행할 수 있습니다. 위치 업데이트의 최소 이동 거리를 10m에서 0m로 변경해 정지 중에도 갱신합니다. 업데이트 간격 요청은 기존 15초를 유지하며 실제 수신 간격은 기기 상태에 따라 달라집니다. 유효한 최근 위치가 없으면 새 위치를 기다립니다.

워치 모드가 켜져 있고 휴대폰 화면이 꺼져 있으면 워치로 전달됩니다. 워치 앱 버전은 변경하지 않습니다. 실제 기기에서 재저장 후 자동 알림 확인이 필요합니다.
